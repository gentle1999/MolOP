# Quick Start

This section covers only what is needed for a first MolOP session. Verify the installation first,
run a real file through either Python or the CLI, then read the object model and common boundaries.

## Recommended order

1. [Install and verify](installation.md)
2. [5-minute start](quickstart.md)
3. Choose [Python API first steps](python-api.md) or [CLI first steps](cli.md)
4. Read [Core concepts](concepts.md) for `batch -> file -> frame` and frame selection

When the examples already run, continue to [Workflows](../guides/index.md) or the
[Reference](../reference/index.md).
