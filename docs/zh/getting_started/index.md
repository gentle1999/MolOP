本区只覆盖第一次使用 MolOP 所需的内容。推荐先验证安装，再用一个真实文件跑通 Python 或 CLI
流程，最后阅读对象模型和常见边界。

    [打开安装页](installation.md){ .md-button }

-   :material-timer-outline: **5 分钟上手**

    从一个计算输出生成摘要并导出结构。

## 推荐阅读顺序

1. [安装与验证](installation.md)
2. [5 分钟上手](quickstart.md)
3. 根据使用方式选择 [Python API 初体验](python-api.md) 或 [CLI 初体验](cli.md)
4. 阅读[核心概念](concepts.md)，理解 `batch -> file -> frame` 和 frame 选择

已经可以运行示例时，可以直接进入[工作流](../guides/index.md)或[参考](../reference/index.md)。

## 这一部分不包含什么

本区不展开每种格式的字段矩阵、完整 CLI 参数和开发者扩展契约。这些内容分别位于[参考](../reference/index.md)
和[开发者](../developer/index.md)区域。
